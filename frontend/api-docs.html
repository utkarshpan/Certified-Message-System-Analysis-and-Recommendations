🛡️ Certified Message System API

Complete API Reference for AI-Powered Message Validation

📖 Base URL & Authentication
Base URL
http://localhost:5000/api
Authentication Header
Authorization: Bearer <jwt_token>
🔐 Authentication Endpoints
POST /auth/signup
Register a new user account
Request
{ "name": "John Doe", "email": "user@example.com", "password": "secure123" }
Response (201)
{ "success": true, "token": "eyJ...", "user": { "id": 1, "name": "John Doe", "email": "user@example.com" } }
POST /auth/login
Authenticate user and get JWT token
Request
{ "email": "user@example.com", "password": "secure123" }
Response (200)
{ "success": true, "token": "eyJ...", "user": { ... } }
✅ Validation Endpoints
POST /validate
Validate message with AI & weather verification
Request
{ "message": "Heavy rain in Mumbai at 6 PM", "category": "weather" }
Response (200)
{ "passed": true, "ruleCheck": { "keywordCheck": true, "locationCheck": true, "timeCheck": true }, "aiCheck": { "isTrue": true, "confidence": 87, "explanation": "...", "suggestions": "..." }, "weatherCheck": { "location": "Mumbai", "realCondition": "Clear", "matchesMessage": false } }
💾 Message Endpoints
POST /messages/save
Save validated message to database
Request (with Authorization header)
{ "message": "Verified message content", "passed": true, "confidence": 87, "explanation": "Message passed all checks", "category": "weather" }
GET /messages
Retrieve user's message history (50 most recent)
Request (with Authorization header)
GET /api/messages
GET /messages/stats
Get user validation statistics
DELETE /messages/:messageId
Delete a specific message
⚕️ Health Check Endpoints
GET /test
Test if server is running
Response
{ "status": "success", "message": "Server running with SQLite!", "database": "SQLite (local file)", "timestamp": "2026-04-28T15:02:15.868Z" }
GET /health
Check system health status
Response
{ "status": "healthy", "database": "SQLite ✅ Connected", "uptime": 120.5 }
⚠️ Error Responses
Code Message Description
400 Bad Request Missing or invalid parameters
401 Unauthorized Invalid or missing authentication token
500 Server Error Internal server error
